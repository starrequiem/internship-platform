# AI 解析提示词 — 将招聘网站原始文本转为结构化实习数据

> 将此文件内容 + 原始文本一起发给 AI（Claude/GPT/Gemini 等），
> AI 会输出可直接入库的 JSON。

---

## 输入

以下是招聘网站（牛客网/Boss直聘/实习僧等）的完整页面文本，包含多条实习招聘信息。

## 任务

从文本中提取每条实习信息，输出 JSON 数组。每条必须包含以下字段：

```json
{
  "title": "岗位名称（必填）",
  "company": "公司名称（必填，个人发布或无法识别填'待识别'）",
  "city": "工作城市（必填，无法识别填'全国'）",
  "district": "区/详细地址（选填）",
  "job_type": "岗位类型（必填，从以下选择：技术开发/产品经理/UI&UX设计/数据分析/运营/市场商务/金融投资/人力资源/财务会计/法务合规，默认'技术开发'）",
  "salary_min": "最低日薪（数字，选填）",
  "salary_max": "最高日薪（数字，选填）",
  "education": "学历要求（选填，如：本科及以上/硕士及以上/不限）",
  "days_per_week": "每周出勤天数（数字，默认4）",
  "duration_months": "实习月数（数字，默认3）",
  "deadline": "截止日期 YYYY-MM-DD（选填）",
  "headcount": "招聘人数（数字，默认1）",
  "description": "职位描述全文（最多3000字）",
  "requirements": "任职要求全文（最多3000字）",
  "contact_info": "联系信息，格式：投递链接/邮箱/电话/二维码等（多行文本）",
  "tags": ["标签1", "标签2"]
}
```

## 规则

1. **每条信息是一个独立岗位**，不要合并
2. **薪资**：格式如 "200-500元/天"、"面议"、"薪资面议"。提取数字部分作为 salary_min/salary_max。如为月薪需换算为日薪（月薪÷22）
3. **城市**：从文本中识别城市名（北京/上海/广州/深圳/杭州/成都/南京/武汉/西安/苏州/远程办公）
4. **岗位类型**：根据标题和描述分类。含"前端/后端/全栈/Java/Python/Go/算法/AI/测试/运维"等 → 技术开发；"产品经理/产品" → 产品经理；"设计/UI/UX" → UI&UX设计；"数据分析/数据科学" → 数据分析；"运营" → 运营
5. **标签**：从标题和描述中提取技术栈和关键词，如：React, Vue, TypeScript, Python, Java, Go, Docker, 可转正, 远程办公, 导师带教, 大厂等
6. **联系信息**：提取投递链接（URL）、邮箱地址（xxx@xxx.com）、联系电话等。将原文招聘链接放在第一行
7. **不要编造**：文本中没有的信息留空

## 输出格式

只输出 JSON 数组，不要任何其他文字：

```json
{
  "items": [
    { "title": "...", "company": "...", ... },
    ...
  ],
  "count": 数字
}
```
