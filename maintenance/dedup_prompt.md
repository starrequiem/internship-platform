# 岗位去重 / 归并提示词

> 用于对 `internships` 表中的实习岗位做去重。AI 可直接按此提示词执行。

## 任务

识别并处理 `internships` 表中的重复岗位，规则如下：

## 去重规则

### 1. 完全重复（必须去重）
- **判定**：`title`（岗位名称）+ `company`（公司）+ `city`（城市）三者完全相同。
- **处理**：只保留一条，删除其余。保留标准（按优先级）：
  1. `description`（职位描述）最长的
  2. 若长度相同，保留 `id` 最小的一条（最早入库）

### 2. 近似重复（归并，可选）
- **判定**：`title` + `company` 相同，但 `city` 不同（同一岗位多城市发布）。
- **处理**：归并为一条，`city` 取首个城市，`description` 头部追加「工作城市：A/B/C」。
  - 但若不同城市的描述/要求差异明显，则视为不同岗位，保留。

### 3. 公司名归一化
- 同一公司的不同写法应归并为统一简称，例如：
  - 「字节跳动」=「字节跳动科技有限公司」
  - 「美团」=「三快在线科技有限公司」
  - 「小红书」=「行吟信息科技（上海）有限公司」
- 保留大众熟知的简称（字节跳动 / 美团 / 小红书 / 阿里巴巴 / 腾讯 / 华为）。

## 输出格式

执行后报告：
1. 删除的完全重复条数、保留的条数
2. 归并的近似重复条数
3. 归一化的公司名清单

## 注意

- 不要删除不同岗位（标题不同、或标题相同但公司不同）。
- 删除前先确认：重复岗位的 `contact_info` 原文链接不同时，优先保留有完整描述的那条。
